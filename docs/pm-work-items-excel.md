# PM WorkItem 批次匯入 — Excel 填寫說明

測試 `bpm-workitemAdder` 會從 Excel 讀取 **專案代號**、**PM 工號** 與 **三筆 WorkItem**，可一次填多個專案後批次執行。

## 檔案位置

- 預設：`data/pm-work-items.xlsx`
- 自訂路徑：環境變數 `BPM_PM_WORK_ITEMS_XLSX`
- 重新產生範本：`npm run generate:pm-work-items-template`

## 工作表「批次」欄位

| 欄位 | 說明 | 範例 |
|------|------|------|
| 專案代號 | BPM 專案 PY 編號 | `PY265-0080` |
| PM工號 | 新增 PM 對應時的人員工號 | `10101209` |
| 序號 | WorkItem 序號（每專案 1～3） | `1` |
| 工作項目名稱 | 固定三項名稱（見下） | `(軟體)軟體建置開發及測試` |
| 預估工時 | 預估總工時 | `100` |
| 警示工時 | 警示門檻工時 | `100` |

### 三項工作項目名稱（請完整複製）

1. `(軟體)軟體建置開發及測試`
2. `(軟體)專案庶務及聯繫`
3. `(協作單位)專案執行`

## 執行

```bash
npm run test:workitem-adder
```

若 Excel 未填專案代號或 PM工號，會依序改用環境變數 `BPM_WORKITEM_PROJECT_CODE` / `BPM_PM_EMP_ID`（或 URL 上的 `empid`）作為後備。
